# CacheSmith Design System

CacheSmith implements 5 core design patterns from `DESIGN_INSPIRATION.md`:

1. **Pattern #12 - Bento Grid:** Modular dashboard structure with distinct visual blocks for simulations, audits, key tools, and generators.
2. **Pattern #20 - Cyberpunk / Dark Mode:** `#07090e` base, vibrant `#00f0ff` cyan, neon `#10b981` emerald, and `#a855f7` purple.
3. **Pattern #10 - Glassmorphism:** Translucent overlays with subtle border strokes (`rgba(255, 255, 255, 0.08)`).
4. **Pattern #3 - Swiss Typography:** Monospaced data displays, crisp contrast, clean information flow.
5. **Pattern #24 - Cybercore Studio:** Live visual simulation bars and interactive feedback.
